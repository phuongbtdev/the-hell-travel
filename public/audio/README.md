# Audio asset slots

`music/` contains eight original 24-second M4A compositions generated by `scripts/build-soundtrack.py`. The runtime selects music by zone mood and adds procedural positional/stereo action sounds (saw, chains, steam, hoofbeats, stone impacts and stamps).

`music/bar.m4a` is an additional original stereo dance track: 120 BPM, 64 beats, 32 seconds, synthesized by `scripts/build-bar-music.py` without sampled songs. Bar playback seeks to the shared beat clock when metadata loads, audio resumes or the client receives a server clock correction. Dance actions and NPCs follow that clock; the global mute button still controls playback. Regenerate with `npm run assets:bar`.

Vietnamese narration, character dialogue and the judge's verdict are defined in `src/world/dialogue.ts` and displayed as large, paginated subtitles. Voice synthesis has been removed. Playback starts after the entry click, and the sound button controls music and effects; subtitles remain available while audio is muted.
